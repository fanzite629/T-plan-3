# V1 独立验收计划

唯一验收基线：`../T成长_运行规则与资源配置_合并方案_20260907.md` 第 8 节；解释计算口径时引用该文件第 6、7 节。测试使用合成数据与隔离浏览器上下文，不读取用户真实 localStorage。

| 基线项 | 实际测试内容 | 通过条件 |
|---|---|---|
| 1 主任务和重点 | 新建 4 个高优先级任务，明确选择主任务；完成主任务并刷新；编辑、延期任务 | 首页重点最多 3 个；已完成主任务标记保留，不自动提升新主任务；延期到系统明天 |
| 2 统一投入 | 周日与周一分别记 40/20 分钟；未完成任务记时；重复完成；编辑投入；删除任务保留/连同删除；导入回放 | 两周分别统计；预计时长不冒充实际；所有入口累计一致；无重复 |
| 3 预算和训练 | 健身 4 天目标与预计分钟分开；同日重复训练；超额预算；零目标有/无投入 | 训练按日期去重；次数不加入小时；超额有差额且可保存；无 NaN/Infinity |
| 4 跨周历史 | 周日任务延期到系统明天；保存总结再完成旧任务；预览并应用下周目标 | 原周任务未消失；快照截止时间/事实不变；前周目标不被下周修改 |
| 5 课表与旁听 | 检查第 1、2、3、6、7、8、9、11、12、13、14、16 周；统计全部无固定冲突旁听 | 第 1–12 周按基线边界变化，合计 16 次；周四微机/周三空；CAD 待定可见；只显示已知节次 |
| 6 体重窗口 | 最近 14 日中稀疏记录、同日更新、无数据、仅前窗数据 | 缺失不补零；窗口/天数/均值正确；最新体重附日期；起始值不冒充当前值 |
| 7 JSON | 导出全部数据→清空→导入预览→确认恢复；损坏 JSON、无效字段、异常引用；取消导入 | 内容完整恢复；失败/取消均保留原数据；清空只影响产品 namespace；保存失败可见 |
| 8 浏览器和 UI | Chrome/Edge 的 file:// 离线打开，CRUD 后刷新，4 页 390px 截图，监听请求和错误 | 两浏览器可用；无外部请求/控制台或页面错误；无横向溢出，主要按钮可操作；无需服务器 |

补充审查：无联网、账号、第三方运行依赖和延后模块；导入文本不执行脚本；字段校验与存储失败路径。代码审查发现与实际失败分别标记，不把未验证的怀疑作为确定缺陷。
