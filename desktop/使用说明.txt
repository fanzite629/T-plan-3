T计划 1.10.0 候选版 · Claude 风格与一句话新建任务

打开方式
本轮仅为隔离候选版，不安装、不升级正式版。请从候选目录双击“打开候选版.cmd”。
保留完整 app、runtime、licenses 和启动器；启动器首次运行生成候选目录内的 data。
Windows 10/11 x64，需要 .NET Framework 4.8。随包提供 WebView2，不需要 Node、Python 或常驻服务。

现有入口
工作台、我的课表、本周任务、任务计时看板、专注统计、数据看板、投入记录和数据管理。
课表与课程详情沿用原有日期、课程及课堂记录；临时调课仍以学校通知为准。
没有恢复固定分类目标、体重健康模块或周总结。

手动编排
普通任务的新建/编辑或课程详情中的学习计划，可进入同一套流程画布。
左边创建和复用工具，中间拖动行动/判断并连线，右边填写具体行动、产出、完成标准及预算。
简表和画布使用同一份课程计划。保存草稿不会生成待办；确认采用时选择需要执行的行动。
资源虚线表示“使用这个资源”，执行实线表示“完成后进入下一步”。判断分支由本人确认。
可保存模板、撤销当前编辑、恢复已保存画布。撤销栈不跨刷新，不改写过去的执行记录。
父流程预算是约束，不与子任务预算重复相加；互斥分支按路径给出估计区间。

执行与计时
选中节点后进入已有计时准备界面，由你确认后开始；仍只有一个活动计时器。
新任务重新设置收尾底线。使用“按本轮预算设置”时从开始专注计算；手动设置的固定底线不变。
暂停/继续、悬浮小窗、追加/拆小/暂缓及实际投入确认沿用原规则。
到点、打开工具、AI 给出答案都不会自动完成任务。记录实际产出、卡点和下一步，由你确认完成。
学习资源调度保留静态工具卡与复制提问模板，不自动发送私人笔记或启动软件。

可选 AI
没有网络或 API 密钥时，手动编排、保存与执行仍可用。
在原生设置窗口自行输入 DeepSeek 密钥；密钥以 Windows 当前用户 DPAPI 保护，不进入业务 JSON。
只有主动请求并确认发送范围才联网。模拟示例明确标注，不表示已经调用真实 AI。
AI 先给建议与差异，由你确认应用到草稿；再由你决定是否正式采用。
支持 TXT/Markdown 摘录（文件不超过20KB，选取不超过8000字符）及手动来源页码。
尚无 PDF/PPT/OCR、图片电路或复杂公式解析；这些资料可自行摘录为文字，不假装已识别。
真实 DeepSeek 服务效果未完成端到端验收；本版开发验证使用 mock 和隔离数据。

数据与备份
候选启动器使用同目录 data；直接启动候选 EXE 使用 %LOCALAPPDATA%\TPlanCandidate1100。业务存储键 tgrowth.v1，导出 schemaVersion 仍为3。
候选数据独立，不读取或合并正式数据；本包启用 API 离线保护。
数据管理可导出 JSON；导入会整体替换，先预览并备份，不会自动合并。
旧备份兼容；新流程字段在旧程序中可能无法识别。回退前先导出升级后的记录，再按发布说明恢复旧版本及对应备份。
Profile 是目录备份，不能作为 JSON 直接导入。不要覆盖正在使用的 Profile。

范围与组件
第一版支持顺序与人工条件分支；没有任意脚本、无限循环、并行计时或自动操作外部软件。
资源路径和网址仅登记为文字，不会自动打开或上传。
使用本地 LogicFlow 2.2.5、WebView2 SDK 1.0.4191.47、Fixed Runtime 152.0.4191.62。
许可证及第三方声明保留在 licenses 和 runtime 中。没有云同步、自动更新或公开上传。
程序未签名，未在另一台干净 Windows 电脑实测；发布说明列出测试证据与限制。

1.9.1 新增
画布空白、节点、连线和分组均支持右键操作。可创建文字或数值常量，连接到行动的参考参数。
端口显示名称并在拖线时检查类型、重复出口与循环。
暖色卡片支持从左到右整理布局；分组可折叠，模板可追加复用。
以上操作不自动开始计时或完成任务，仍由你确认执行。
