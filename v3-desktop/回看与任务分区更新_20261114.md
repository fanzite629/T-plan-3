# T计划 v3.7.0 · 回看与任务分区

## 回看

- 统一黑白灰卡片、边框、按钮和图表，适配浅色、深色以及窄窗口。
- 顶部支持日、周、近 30 天范围与日期跳转，明确显示已记录分钟、时间记录段数、范围内安排的完成数、有记录的日期数。
- 时间分布仅显示已保存的记录，不把正在运行或暂停的计时当成已记录事实。没有起止时刻的补记仍计入总时长。
- 逐条记录直接展示，可按名称、内容或备注搜索，按时间 / 随手反思 / 完成状态和分类筛选。筛选只影响明细，不改变汇总或 AI 复盘范围。
- 点击记录标题或编辑按钮即可修改，顶部可直接补记时间。写入失败时保留原记录和编辑表单。
- 个人反思与“下次从哪里继续”按日期范围独立保存。引导按钮只追加写作开头。自动保存失败时，本次打开期间保留未保存文字，切换范围后可返回重试。
- “查看记录 / 写反思 / AI 复盘”提供快捷定位；复制复盘包括当前未保存的个人文字，方便保留。
- AI 草稿单独展示来源、生成时间、是否包含反思及下一步建议。用户明确选择后才追加建议，不能重复追加；源内容变化时提示过期并禁用采用，生成失败保留已有草稿与反思。

## 按课程或项目整理任务

用户已选择任务分区，功能导航入口保持原有位置。

1. 点击侧栏“我的任务”右侧的“＋ 分区”，填写名称后创建。
2. 可拖入任务、在任务详情中选择分区，或用“添加已有任务”搜索并批量归类。
3. 分区支持折叠、重命名和上移 / 下移；这些设置会在重启后保留。
4. 可以直接在分区内新建任务，日期或本周未定归属独立设置。
5. 移除分区需要确认，任务会回到原来的日期任务组，任务、计时和反思不删除。

归类只修改任务的 sectionId；分区列表保存在 settings.taskSections，跟随原有 JSON 导出和本机 SQLite 保存。没有强制预置或自动归类真实任务。已归类的任务只在对应自定义分区显示，避免侧栏重复；原有主任务和置顶标记保留。
