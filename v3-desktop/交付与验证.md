# T计划 v3 3.0.0 交付记录

以用户提供的 T计划_v3 (2).html 为界面与功能来源，单独构建 v3-desktop，未修改旧版本源码和日常用户数据。

实现：WinForms + 随包 WebView2；原生 C# 数据层使用 Windows winsqlite3；SQLite storage 表保存 JSON 状态，WAL + FULL 同步，每次保存以单条事务提交。API Key 使用当前用户 DPAPI 加密。任务首次启动为空白；保留源 HTML 内置课程表与其他功能。

PASS：Windows x64 EXE 编译；真实 WebView2 页面启动；UI 创建任务写入 SQLite；刷新恢复；进程关闭再启动恢复；独立 Python SQLite 读取中文任务及 integrity_check=ok；计时/回看/本周/决策树/课表页面导航；引号/中文/emoji/换行数据库往返；密钥加密与读取；页面无捕获到的脚本错误。

NOT RUN：干净外部 Windows 安装/卸载；在线模型接口；完整计时长时间运行；JSON 导入导出全链路；断电恢复。
NOT VERIFIED：公网下载地址与托管（未上传）；数字签名（未签名）。

成品：release/TPlan_v3_Setup_3.0.0_x64.exe。
构建：powershell -File build.ps1，然后 Inno Setup ISCC installer.iss。
数据：%LOCALAPPDATA%\TPlanV3\tplan.sqlite3；卸载不删除此目录。备份请关闭程序后复制整个目录，或用界面 JSON 导出。

此数据库为本地存储，不提供账号和云端同步。SQLite 保存的是应用完整 JSON 状态，并非逐任务关系表。
`n系统依赖：Windows 10/11 x64，.NET Framework 4.8。WebView2 已随安装包提供；未在缺少 .NET 4.8 的系统验证。
