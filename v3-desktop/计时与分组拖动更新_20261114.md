# T计划 v3.8.0 · 计时、小窗与侧栏分组排序

## 计时页面

- 使用与回看、AI 提议等页面一致的黑白灰卡片与按钮；浅色、深色和窄窗口均适配。
- 将准备开始、专注中、已暂停、时间到和待记录分开显示，倒计时突出剩余时间，旁边显示已专注时间和暂停次数。
- 可从任务选择器关联任务、选常用时长或自定义 1–180 分钟，也支持正计时。
- 暂停、继续、增加 5 分钟与结束记录直接可见。暂停时延长会保持暂停；到点后延长会继续计时。
- 结束后，填写“做了什么”“卡在哪 / 想法”“下次从哪里继续”，完成任务需要单独勾选。
- 填写内容自动保存为草稿，切页和重启后保留；保存记录成功后才计入统计。保存失败保留计时和输入，提供重试。
- 保存成功提供记录回执，可以直接打开该记录，或前往回看。今天已保存的记录可直接点击编辑。

## 原生计时小窗

- 黑白灰按钮、数字、进度条，跟随主页面深浅主题。
- 标准和紧凑布局可切换；可拖动非按钮区域移动，长任务名称悬停显示全文。
- 置顶状态可切换，“返回”收起小窗并回到计时页。
- 暂停 / 继续、增加 5 分钟、结束记录与主页面同步。
- F8：暂停 / 继续；Ctrl+Enter：结束并回到记录填写；Esc：返回主页面。
- 结束不会自动替用户完成任务或直接保存记录。

## 侧栏分组位置

置顶、今天、之后与未定和自定义分区现在共享同一套顺序。

1. 拖动分组标题或左侧拖动柄，跟随插入线放到想要的位置。
2. 可以把课程或项目分区放到置顶之上，也可以移动默认分组。
3. 点击分组菜单或拖动柄，可以用按钮上移 / 下移；聚焦拖动柄后可用 Alt+↑ / Alt+↓。
4. 顺序保存到本机，重新打开仍保留。

分组排序不改变任务日期、归属、完成状态或计时记录。任务条目原有的拖动归类保持独立。
