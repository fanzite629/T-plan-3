# 橙橙桌宠与学习助理 · 3.9

为 T计划自己的 Windows 桌面版实现，跟随 T计划启动及退出。主窗口最小化时，桌宠仍独立显示在其他软件上方。

## 使用

- 拖动人物或上方提示条调整位置；单击招手，双击聊天。
- 右键可左右移动、自动漫游、跟随鼠标、停止、切换人物大小、开关置顶和招手、设置本轮休息提醒或收起。
- 侧栏底部“桌宠与助理”和系统托盘均可找回桌宠。
- 提示条与现有计时同步；专注计时进行时暂停自动移动，可从右键菜单暂停、继续或结束填写记录。
- 助理面板可切换小屋、学习、娱乐、看书、生活五种场景；Ctrl+Enter 发送问题。
- 使用 T计划原有模型设置。对话可结合当前任务、今日时间记录、个人反思和下次行动，帮助解释问题、选下一步、拆解任务和复盘。
- 生成任务后点击“检查任务草稿”，修改日期和时长，再通过原来的确认按钮写入。普通对话和复盘不直接修改记录。

## 形象与范围

待机及移动直接使用用户提供的原图，人物比例、面部和细节未做简化；原始 PNG 的 SHA-256 保持一致。短招手序列基于该原图制作，可在右键菜单关闭。移动采用原画平移，未制作逐帧步态或 Live2D 骨骼模型。

当前助理的操作范围是 T计划任务草稿、计时及学习对话，没有任意电脑控制、网页搜索或自动读取文件工具。20 分钟休息提醒属于本次软件运行，退出后不继续。

## 保存

任务及记录仍在本机 SQLite。桌宠偏好保存在 `pet-settings.json`；最近 40 条聊天保存在 `pet-chat.json`，两者均位于 `%LOCALAPPDATA%/TPlanV3/`。API 密钥继续使用原有 Windows 账户加密存储。

对话中尚未点击“检查任务草稿”的草稿仅在当前会话内可操作；已检查的草稿进入 AI 提议页面持久保存。历史聊天会在重启后恢复。

## 验证记录

核心规则 57 项；桌面回归覆盖原有页面、数据、任务确认、失败回滚及重启恢复；新增桌宠集成检查覆盖显示、尺寸、移动模式、真实事实摘要、草稿幂等与专注期间停止移动。实际原生窗口验证透明显示、快速拖动、右键移动、双击对话、五个场景、收起找回和重启恢复。

使用既有 DeepSeek 配置及隔离虚构数据完成真实调用：区分已记录的 12 分钟与尚未结束的计时，生成两条日期未定的任务，经检查和确认后才写入；复盘正确引用“例题还需独立重做”和“先列出已知量”，未新增任务。测试中复制的加密凭据在测试后移除，未改动正式版任务和记录。

详细机器验收结果位于本机 `output/playwright/`，包括 `companion-qa-results.json`、`companion-native-qa-results.json`、`companion-live-results.json` 和 `timer-native-qa-results.json`。升级脚本核对验收文件与待安装程序，备份原程序、快捷方式及数据库后再更新。
