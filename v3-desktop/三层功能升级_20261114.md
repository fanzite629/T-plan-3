# T计划 3.2：提议、复盘、本周安排

已于 2026-11-14 安装到 `D:\Soft\TPlanV3\T计划 v3.exe`。桌面原有 `T计划.lnk` 继续指向此程序，橙色 T 与小叶子图标保留。

## 第一层：先提议，再确认

左侧新增 **AI 提议**，支持任务、决策树、周计划三类草稿。

- 输入目标，选择 **生成 AI 草稿**，或不联网的 **生成本地模板**。
- 草稿中可以修改标题、日期、预计时长；树可以修改步骤、检查点与分支条件。
- 草稿保存后仍未加入正式安排。点击 **确认写入** 才添加或调整任务；放弃草稿不会改变任务。
- 确认操作不会重复执行；周草稿对应的任务或重点已变化时，会拒绝旧草稿。
- 决策树入口的 **AI 提议** 已接通。确认树后仍需在决策树中选择路径、点击 **加入安排**，只添加到首个未解决的检查点。
- 本地周模板保留已有任务的日期，以便手工调整，不冒充智能排程。没有已有任务时，按输入的各行生成候选任务。

## 第二层：复盘三段布局

**回看** 的日、周、近 30 天均提供：

1. **记录事实**：已记录时长、记录段数、范围内安排及勾选完成数量。未记录不推断为未做，时间不推断为掌握。
2. **我的反思**：个人文字及 **下次从哪里继续**，输入后自动保存，每个日期范围独立保存。
3. **AI 草稿**：生成结果单独保存，带来源、生成时间和内容变更提示。仅点击追加按钮才把建议追加到“下次继续”，不会覆盖已有文字。

原有时间线、分类统计、热力图、逐日明细和 Markdown 导出保留在页面下方的 **查看原有统计、时间线与逐条记录** 中。Markdown 也包含新增反思与标注来源的草稿。

任务详情也有“下次从哪里继续”，计时进行页显示这条提示；关联任务的计时收尾可以保存新的继续点。收尾输入会保存为当前计时的临时内容，返回主窗口不会擦掉刚输入的文字。

## 第三层：周重点与本周未定

**本周** 页面增加：

- 周重点，建议 1–3 件事，按周保存。
- 本周可投入分钟；留空时沿用每日上限 × 7，可设置 0。显示已安排、未定日期、已记录时长及超量提示。
- 第八列 **本周未定**。任务有独立的所属周、日期为 null，不会变成今天或逾期任务。
- 七天与未定栏之间可以往返拖拽；移动后保留横向滚动位置。也可在任务详情里设置日期或所属周。
- 计划总量包含已完成任务；“已记录”来自时间记录，不把二者相减冒充剩余工作量。

## 模型连接与数据

沿用现有模型设置与加密密钥。支持 OpenAI 兼容的 Chat Completions 接口和 Anthropic Messages 接口。网络请求由桌面进程发送，避免网页跨域限制；60 秒超时，可主动取消。

点击生成才发送内容。任务与树发送本次目标；周计划另带所选周的未完成任务摘要和周重点；复盘发送所选范围的记录摘要和备注，个人反思只有勾选后才附带。API Key 仍由 Windows 当前账户加密保存，不进入 JSON 导出。

本次未使用真实付费模型，未将正式学习数据发送到模型服务。AI 网络路径用本机模拟服务验证；实际服务的密钥、额度、模型输出质量，以及 Anthropic 的线上调用仍需以用户自己的服务为准。本地模板、个人反思和周安排可以离线使用。

接口实现参考：[OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat)、[Anthropic Messages API](https://platform.claude.com/docs/en/api/messages)。
