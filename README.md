## 日常使用

1. **今日**：新建任务，选定1个主任务；最多另显示2个当日高优先级任务。完成后不会自动补上新主任务。
2. **本周**：填写可安排的自由时间，修改八类目标，查看正式课程和可选旁听。点击课程查看场次、编辑学习计划或记录本次学习；今日课程也可直接点击。
3. **看板**：按教学周查看目标与实际、每日投入、体重趋势和时间配置。首页仅提供小入口，完整图表放在看板。
4. **记录**：按课程查找历次计划、实际完成内容和卡点，查看或复制给ChatGPT；同名课程在不同日期的记录分别保留。实际分钟另行填写。体重一日一条，健身按训练天数统计。
5. **周总结**：填写三个复盘问题，再生成、保存或复制文本；修改问题后需重新生成，防止遗漏。调整下周目标前先预览，再确认应用。

分类为：学校专业课、六级/英语、考研数学、电力系统分析、AI / Agent、健身、财务/投资、其他。AI / Agent复用任务、实际投入和学习成果字段，建议写清楚可验证的结果。

## V1.2 课程学习计划与课后记录

- 从今日或本周课表点击某一次课程。计划按“课程场次ID＋具体日期”唯一保存，同一门课不同星期、不同教学周互不覆盖；教师、教室、课程周次及特殊日程提示保留。
- “编辑学习计划”填写主题、课前问题及保底／达标／进阶三条线，每行一项。初始为空，不猜测章节，不自动生成知识点；进阶可留空。
- “记录本次学习”填写本次实际完成／学会内容，勾选解释、画图、做题、讲给别人、仍有卡点，填写具体问题并自行选择状态。可以先记成果，之后补计划；两种编辑互相保留。
- 自评不自动推断：达到保底不等于达标，勾选证据或记时不会自动提升状态，未达到进阶不判定失败。
- “复制本节课程给ChatGPT”生成带日期和现有记录的规划文本；“复制本次学习记录”包含三层目标、实际成果、证据和卡点。文字始终可见，自动复制失败时可手动选取；不调用任何AI API。
- 保存后可创建课后复盘任务，默认预计30分钟且可修改；正式课程归学校专业课，电力系统旁听归电力系统分析。同一节课再次点击会打开已有任务。完成任务不自动产生投入，使用“记投入”登记真实分钟；本节记录本身不计时，避免重复。
- “记录”页按课程名称筛选，按日期倒序查看历次记录；新生成周总结带本周课程复盘事实和逐课成果、证据、卡点。已保存的历史总结保持原快照。
- 看板只增加已复盘、自评保底、自评达标、有卡点四个次数。按已发生的课程日期统计，三档自评互斥，卡点可并存。没有课程掌握率、学习ROI或新图表。
- 当前数据版本是 `schemaVersion: 3`，兼容读取／导入版本1和2，旧任务补空课程关联，旧总结原文与统计不重算。存储键仍为 `tgrowth.v1`；导出版本3，旧程序不保证读取新备份。无需清空已有数据。
- 单条主题最多500字，成果和卡点各最多10000字；每组目标最多50项、每项1000字。保存失败保留编辑框内容，并显示原因。

## V1.1 看板和历史兼容

- 新周AI / Agent默认目标3.5小时，可在本周目标中修改。其他初始目标与30小时自由时间预算保持原值，因此新周默认分配32.5小时，显示超额2.5小时；可自行调整，不自动削减某一类目标。
- 已保存的旧周计划为AI / Agent补0，保留原来的历史分配；新建或此前未保存的周计划使用新默认。已保存旧总结的文本、截止时间与事实快照保留。
- 原“股票/理财”显示为“财务/投资”，内部分类仍是 `stocks`，历史记录不重建。旧中文分类别名也可读取/导入；冲突分类键会拒绝整份导入，避免丢失数值。
- V1.1时数据版本升级为 `schemaVersion: 2`；当前V1.2继续升级为版本3（见上）。首次读取仅在内存中升级，成功保存时才写入，仍使用原 `tgrowth.v1` 存储键。
- 看板实际数据截止所选周日；若查看本周，截止今天；未来周不生成实际趋势。页面显示截止日期。实际分钟仅来自统一投入记录，不累加任务预计时间或旁听对象。
- 目标比较图按小时显示七个时间类别，健身单独显示目标天数/实际训练天数。每日图和配置图包含健身实际分钟，不包含训练天数。
- 体重图显示截至统计日的28日窗口：灰点为有效体重，蓝线为包含当日的7日滚动均值。缺失不补0；每一点显示有效样本数，不足7个样本以空心点和文字注明。无有效样本处断线。纵轴按实际范围缩放并标注上下界。
- 配置图的实际分母是“已记录自主投入时间”，不是全部生活时间；目标分母是计划分配，含健身分钟预算和超过电力目标的旁听预留。双方有分母且某类相差至少10个百分点时，仅提醒周总结时考虑再平衡。
- 根据后续补充，时间资产配置卡增加实际投入饼图，沿用同一分类颜色和分钟统计；图例显示占比与小时。没有实际投入不画饼，零投入类别不生成扇区，只有一个类别时显示完整圆。原目标/实际比例条保留，便于精确比较。健身只计投入分钟，训练天数不参与饼图。
- 财务/投资的隐藏选项继续作用于目标卡；完整看板仍保留所有类别及其真实投入，确保分母完整，避免隐藏历史时间。

## 数据口径

- 学习时长来自投入记录，不用预计时间冒充实际时间。未完成任务也可记投入，跨天学习分开记录。
- 健身目标以天为单位，健身预算另以小时设置；记录训练时长不会自动增加训练天数。
- 电力系统分析目标包含旁听。旁听预留在目标内不重复占预算；超过该目标的预留部分额外占用预算。实际参加一次只创建一条投入，再次编辑不会重复累计。
- 删除任务可以保留历史投入；连同投入删除需要明确确认。取消已参加旁听的时间预留仍保留参加事实和投入。
- 跨周延期保留原日期及变更历史。本周任务包括原计划或改期历史曾安排在本周的任务，按任务ID去重。
- 已保存的周总结是该时点快照，之后完成任务或修改目标不会自动改写它；主动覆盖快照需确认。
- 体重页面是截至今天的最近7日/前7日均值，周总结是周一至周日窗口。缺失不补零，并显示有记录的天数。
- 财务/投资初始目标0，沿用“空仓期冻结至2026年底”的原默认，用户可修改或隐藏目标卡。

## 备份与恢复

数据保存在当前浏览器的 localStorage，键为 `tgrowth.v1`。桌面左下角“数据管理”，手机页面右上角“数据”，均可导出 JSON、导入 JSON 或清空。

- 导出包含版本号、导出时间和全部持久化记录。
- 导入先校验字段、日期、重复ID及关联，再展示预览；确认后整体替换，不自动合并。损坏文件不会覆盖原数据。
- 清空只移除 T成长自己的键。导入或清空前建议导出备份。
- 更换浏览器、移动文件位置、无痕窗口或清除浏览器数据后，原数据不保证仍可见。迁移请使用 JSON 备份。
- 写入失败会显示“未保存”；另一个窗口修改数据时，当前页会要求刷新，避免覆盖。
- 复制总结只复制文本，不发送给任何服务。若浏览器不允许直接复制，可手动复制已选中文本。
